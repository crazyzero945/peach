使用说明

这是什么

一个只在自己电脑上运行的媒体库：扫描本地文件夹，生成海报墙，然后搜索、筛选、播放。参考了 Peach 的产品思路，代码是独立实现，只用 Python 标准库 + 一个网页文件，不需要 Node、ffmpeg 或任何第三方包。

添加媒体目录

点顶部「目录」，填入文件夹的绝对路径（例如 D:\Movies），添加后自动开始扫描。也可以直接把文件夹拖到 start.bat 上启动，或命令行运行 python shelf.py --root "D:\Movies"。目录支持多个，配置保存在 config.json。

首次启动带了一个 demo-library 演示库（8 条占位影片，只用来展示界面，里面的视频不是真文件、不能播放）。在「目录」里移除它并删掉 data/shelf.db，就能从零开始建自己的片库。

扫描会做什么

  • 递归识别常见视频格式；海报、封面、字幕、NFO、截图等附属文件不会混进馆藏。
  • 同名 .nfo 里的标题、年份、评分、类型、演员、简介会被读进来；没有 NFO 时从文件名推断编号、年份和清晰度。
  • 封面优先取同名图片，其次 poster.jpg / folder.jpg / cover.jpg 等；都没有就用渐变占位卡。
  • 人工修改永久保留：改过标题、标签、简介的条目，重新扫描只刷新大小和文件时间，不会覆盖你的编辑。
  • 文件移走或删除只标记为「已丢失」，观看记录、收藏和备注都留着。

在线刮削

点顶部「刮削」→「刮削未完成的」，会从 Wikidata + 维基百科 自动抓取原名、年份、导演、演员、题材、剧情简介与海报，零配置、不需要 API Key。匹配不准时，在影片详情里点「手动匹配」自己挑条目。也可以在刮削面板里填 TMDB / OMDb 的 Key 作为补充源（Key 只存在本机 config.json）。

  • 默认只填空字段，不会覆盖已有的 NFO 资料；勾选「覆盖已有资料」才会替换。
  • 人工编辑过的标题 / 标签 / 简介永远保留，刮削只补导演、原名、海报这类空缺。
  • 海报缓存在 data/posters/，与扫描到的本地封面分开存，重新扫描不会丢；详情里可一键「用回本地封面」。
  • 失败的条目会标记出来，可以「重试失败的」，或用手动匹配指定正确条目。

播放

点海报上的播放按钮即可在网页里播放，服务支持 HTTP Range，可以任意拖动进度、自动续播。mkv / avi 等浏览器不支持的格式，点「系统播放器」用本机播放器打开。

数据在哪

全部在本目录：data/shelf.db（SQLite 馆藏与记录）、config.json（媒体目录与端口）。服务只监听 127.0.0.1，不上传任何东西。删掉这两个文件即可重置。

快捷键

/ 聚焦搜索 · Esc 关闭弹窗 · 搜索支持空格分隔多个关键词（同时命中）。
