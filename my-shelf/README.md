# 我的片库 · My Shelf

一个**本地优先、零第三方依赖**的影片媒体库：指定文件夹即可扫盘建档，生成海报墙，支持搜索、多维筛选、排序、详情编辑、在线播放与续播、统计和导出。

本目录是 [peach-mitao/peach](https://github.com/peach-mitao/peach) 的一个**独立轻量派生实验**，放在 fork 里作为 `my-shelf/` 子目录，不改动上游任何主线代码。它只借鉴 Peach 扫描层的三条设计不变量，其余全部用 Python 标准库重新实现：

1. 海报 / 截图 / NFO / 字幕等**附属文件不入库**；
2. **人工编辑过**的标题、标签、评分、收藏等字段，重扫时**不被覆盖**；
3. 文件从磁盘消失时**只标记 `missing`，不删除记录**（外挂盘离线不会丢数据）。

> 说明：Peach 的名称与 Logo 有其商标政策，本项目不使用其名称与标识，也不分发其代码。上游 `peach/` 仓库主体仍遵循其原有的 AGPL-3.0-or-later 许可；本子目录为独立实现。

## 为什么另做一份

Peach 本身成熟度很高（v0.57.0、6800+ 提交、300+ 后端模块），但在它主线之上做二次开发要背一整套环境负担：Python 3.14 + uv、几十个依赖、全量测试锁，以及 AGPL 的传染性与商标政策。`my-shelf` 把门槛降到**只要一个 Python 3.9+**，双击即用，方便自由改造。

## 运行

```bash
# 方式一：双击 start.bat（Windows），或把媒体文件夹直接拖到 start.bat 上
# 方式二：命令行
python shelf.py --root "D:\Movies" --port 8765
python shelf.py --root "D:\Movies" --root "E:\Series" --no-browser
```

启动后浏览器打开 <http://127.0.0.1:8765>。首次启动会自动扫描 `--root` 指定的目录；也可以在网页右上「设置」里增删目录并重新扫描。

服务**只监听 127.0.0.1**，不对外网开放；所有文件路径从数据库读取，不接受客户端传入任意路径。

启动时的容错：

- 如果 8765 上已经有一个片库在跑，再双击 `start.bat` **不会重复启动**，而是直接打开已运行的页面。
- 如果端口被其他程序占用，会**自动顺延到 8766、8767…** 并在窗口里打印真实地址；12 个端口全满才给出中文提示。
- `start.bat` 会依次尝试 `python`、`py -3`，都没找到才提示安装并说明勾选 `Add Python to PATH`，不会一闪而过。

## 直接打开网页也能用（离线演示模式）

`web/index.html` 是单文件、零依赖的页面。即使**没有启动 Python 服务**（例如用静态文件服务器、或编辑器里的 HTML 预览直接打开），它会自动探测 `/api/stats`，探测不到就切换到**内置演示模式**：

- 内置 8 部示例影片，海报由内联 SVG 生成，不请求任何外部资源；
- 搜索、标签 / 年份 / 格式 / 清晰度 / 目录筛选、排序、分页、网格 / 列表切换、深浅主题、详情编辑、收藏、已看、统计、重复检测、CSV 导出**全部可交互**（数据存在内存里，刷新即还原）；
- 页面顶部有提示条说明当前是演示数据，并给出启动真实服务的方法；
- 磁盘 / 扫描 / 系统播放器这类必须依赖本机文件的操作会给出引导提示，而不是报错。

也就是说：**以静态方式打开 → 完整可点的演示；启动 `shelf.py` → 连接你自己的真实片库**。连接后端后页面会自动切换，不再显示演示提示条。

关于播放：演示数据和 `demo-library/` 里的占位文件都不是真实视频，点击播放会显示一个 **Canvas 演示画面**（可暂停 / 继续、有进度条、结束会标记已看），不会再黑屏报错。浏览器不支持的编码（如部分 MKV / HEVC）也会走同样的降级，此时可用「系统播放器」交给本机播放器。加入自己的影片后即可正常串流播放与续播。

| 参数 | 说明 |
| --- | --- |
| `--root` | 媒体根目录，可重复指定多个；不传则读取 `config.json` |
| `--port` | 端口，默认 `8765` |
| `--no-browser` | 不自动打开浏览器 |
| `--db` | SQLite 路径，默认 `data/shelf.db` |

## 功能

- **扫盘**：递归识别常见视频格式，解析文件名中的年份、分辨率、来源、分卷；读取同名 `.nfo` 的标题 / 年份 / 评分 / 剧情 / 类型 / 演员；优先用同名海报，其次 `poster.*` / `folder.*` / `cover.*`，最后目录内第一张图。
- **海报墙**：网格 / 列表双视图、浅色 / 深色主题、卡片悬停操作、缺失文件灰显。
- **搜索筛选**：标题 / 原名 / 剧情 / 标签全文搜索；按标签、年代、格式、清晰度、目录、观看状态、收藏筛选；按标题 / 年份 / 评分 / 大小 / 加入时间排序。
- **详情编辑**：标题、原名、年份、评分、标签、剧情、收藏、已看；编辑后打 `edited` 标记，重扫保留。
- **播放**：内置 HTML5 播放器，服务端支持 **HTTP Range**（206 分段），可拖动进度、续播。
- **统计**：总数、总容量、格式 / 年代分布、已看 / 收藏 / 缺失 / 人工编辑数量、分面计数。
- **重复检测**：按文件大小 + 采样哈希找出疑似重复，辅助整理。
- **导出**：CSV 全量导出，便于备份或迁移。
- **封面与串流**：`/cover/<id>` 直接输出本地图片；`/stream/<id>` 支持 Range 与常见视频 MIME。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/stats` | 概览统计 |
| GET | `/api/facets` | 各维度分面计数 |
| GET | `/api/items` | 列表，支持 `q` `tags` `year` `ext` `resolution` `root` `show` `sort` `order` `page` `page_size` |
| GET | `/api/items/<id>` | 单条详情 |
| PATCH | `/api/items/<id>` | 局部编辑（可改字段见上） |
| POST | `/api/scan` | 触发重新扫描 |
| GET | `/api/scan/status` | 扫描进度 |
| GET/PUT | `/api/roots` | 读取 / 保存媒体目录 |
| GET | `/api/duplicates` | 疑似重复文件 |
| GET | `/api/export` | CSV 导出 |
| GET | `/cover/<id>` | 封面图 |
| GET | `/stream/<id>` | 视频流（支持 Range） |

## 目录

```
my-shelf/
├── shelf.py          # 标准库 HTTP 服务 + SQLite + 扫描 / NFO / 封面 / Range
├── web/index.html    # 单文件海报墙（无构建、无依赖）
├── start.bat         # Windows 一键启动
├── config.json       # 媒体目录配置（运行时生成）
├── data/shelf.db     # 索引数据库（运行时生成，建议加入 .gitignore）
└── README.md
```

## 已知边界

- 封面取本地图片；没有图片时显示渐变占位卡。未内置 ffmpeg 截帧与在线元数据刮削源。
- `demo-library/` 是占位文件，只用于看界面与验证扫描链路，真实播放请添加自己的影片目录。
- 离线演示模式的数据只存在浏览器内存里，刷新页面即还原；真实模式下所有改动写入 `data/shelf.db`。
- 浏览器能否直接播放取决于编码格式（H.264/AAC 的 MP4 兼容性最好；MKV/HEVC 可能需外部播放器）。
